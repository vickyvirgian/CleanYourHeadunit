# Native Nothing-inspired UI

Reference: https://github.com/wangbh030722/vibe-nothing-ui-design and its SPEC.md.

The launcher and local head-unit app adapt the monochrome palette, circular dot geometry, Doto display type, Geist UI type, Geist Mono labels, sparse background dots, 8dp card radius and 6dp button radius using native Android views. Buttons invert black/white. Red is reserved for error/needs-input signals; no decorative red, gradients, web rendering or blur cost.

Android text and touch sizes are increased for a vehicle display. Background dots are drawn behind opaque cards. No proprietary Nothing fonts or assets are included. The reference project is independent of Nothing Technology Limited; this project likewise does not imply endorsement.
